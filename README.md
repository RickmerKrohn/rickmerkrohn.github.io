# Rickmer Krohn — Personal Website

A lightweight, responsive academic portfolio for research in multisensory
robot learning. The site is plain HTML, CSS, and JavaScript and can be
deployed directly with GitHub Pages.

## Local preview with Jekyll

```sh
bundle install
bundle exec jekyll serve
```

Then open `http://localhost:4000`.

If Bundler was installed with `gem install --user-install` and `bundle` is not
on your path yet, run this once in the current shell first:

```sh
export PATH="$(ruby -e 'print Gem.user_dir')/bin:$PATH"
```
